Windows games,
poured onto your Mac.

Rum is a free, open-source game library for Apple Silicon. Drop in an .exe, press Play, and Wine does the rest.

Download for macOS View on GitHub
brew install --cask lunguini/tap/rum

Features

Wine, but a bit sweeter.

Rum wraps Wine in a native SwiftUI app, so you spend your time playing instead of editing prefixes.

A real game library

Cover art, play time, Recently Played and one-click launch for every game and app you add.

Modern graphics

DXVK, DXMT, WineD3D and D3DMetal, with Rum checking the renderer before launch instead of after a crash.

Bottles made easy

Create and manage Wine bottles without the terminal. Winetricks, environment and runtime settings are built in.

Multiple Wine engines

Keep Gcenx and Sikarugir engines side by side and pin a different one to each bottle.

Per-game graphics

Run one game on DXMT and another on DXVK in the same bottle, and switch from the library when one misbehaves.

Command line too

The rum CLI lists, creates and runs bottles for scripting and shell setups.

Rum vs Whisky

Picks up where Whisky left off.

Rum started as a fork of Whisky, which is no longer maintained. Here's what's been added on top.

WhiskyRum
MaintainedNo, archivedActively developed
WineOne bundled, older Wine buildCurrent Wine Staging from Gcenx, plus Sikarugir engines
Multiple Wine enginesOne engine for everythingInstalled side by side, pinned per bottle
Graphics backendsD3DMetal, DXVKDXVK, DXMT, WineD3D and D3DMetal
Per-game graphics backendOne setting per bottleEach game picks its own, switchable from the library
Game libraryPinned programs per bottleEvery bottle in one library, with cover art and play time

Thanks to Isaac Marovitz and everyone who built Whisky. Rum wouldn't exist without it.

Install

Up and running in a minute.

Install Rum 2 with the new game library, or keep using Rum 1.

Rum 2 Beta

The redesigned game library, kept up to date through Homebrew or in the app. Please report what you find.

brew install --cask lunguini/tap/rum
  1. Or download Rum.zip from the latest release and move Rum.app to Applications.
  2. On first launch Rum installs Rosetta, a Wine engine, graphics runtimes and a default bottle for you.
  3. Drop an .exe on the window and press Play.

Rum 1 1.x

The previous version, kept for anyone who needs it.

brew install --cask lunguini/tap/rum@1
  1. Only one version can be installed at a time. Run brew uninstall --cask rum first; your bottles stay put.
  2. Or download a v1.x build from Releases.
Apple Silicon (M-series) Mac macOS Tahoe 26.0 or later Downloaded the zip? Right-click Rum.app → Open the first time, as Rum isn't notarized yet
